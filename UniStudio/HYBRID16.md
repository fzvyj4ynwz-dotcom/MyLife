# UniStudio 16.0 — Hybrid Cloud (development preview)
This branch preserves the original PWA and its existing local data keys. Hybrid sync is opt-in. The state snapshot is mirrored into IndexedDB and, when the vendored SQLite engine is installed, a SQLite database exported back into IndexedDB. The original save path stays authoritative.
## Deployment prerequisites
1. From a trusted development machine install pinned sql.js 1.13.0: `npm install --no-save --ignore-scripts sql.js@1.13.0`. Copy node_modules/sql.js/dist/sql-wasm.js and sql-wasm.wasm into UniStudio/vendor; include the package MIT license. Verify the package integrity and commit the assets. Until then the existing local archive and IndexedDB mirror work without SQLite.
2. Create a private Supabase project, apply hybrid16.sql in SQL Editor, create Sara's Auth account, and enter only project URL and publishable key in the app. Do not commit credentials. Session is kept in sessionStorage, never passwords.
3. Before publishing, test on an actual iPad, offline restart, reconnect, upload, authentication, and simultaneous edits. Confirm row isolation with two test accounts.
## Scope and safety
Snapshot uploads use revision compare-and-swap. A changed remote snapshot or a first-time second device is treated as a conflict; the app offers remote backup download, never auto-overwrites local data. Manual import/reconciliation is required in this preview. An acknowledgement clears the pending record only if the local snapshot still matches. Local state is retained. Library scans, separate document/audio blobs, avatar and independent localStorage preferences are not synchronized. PDF/OCR dependencies may need internet on first load; background sync is not guaranteed on iPadOS. No cloud project is provisioned by this branch.
